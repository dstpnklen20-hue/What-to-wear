# What to wear

Android-приложение, которое показывает подробную погоду на день и подбирает одежду из вашего гардероба.
Работает офлайн, все данные — только на устройстве, аналитики и трекеров нет.

## Возможности

- **Точная погода.** Почасовой прогноз сразу по нескольким моделям (ECMWF IFS, ICON, GFS, best_match от Open-Meteo)
  плюс MET Norway для сверки и как резервный источник. Итог — взвешенное среднее; если модели расходятся
  (по температуре больше 3 °C или по осадкам), показывается пометка «прогноз неуверенный».
- **Гардероб.** Фото с камеры или из галереи, категории, теплота 1–5, водо- и ветрозащита, слой, стиль, цвет, сезон,
  отметка «в стирке», поиск и фильтры, экспорт и импорт в JSON (фото внутри файла).
- **Подбор одежды.** Локальный алгоритм на правилах: ощущаемая температура за время вне дома, перепад за день
  (что снять днём), дождь, ветер, УФ-индекс, снег и гололёд. Кнопка «другой вариант», объяснение выбора и честные
  предупреждения о том, чего не хватает в гардеробе.
- **Персонализация.** Вечером — «было холодно / нормально / жарко»; личная поправка сдвигается по отзывам.
  Её можно задать и вручную («я мерзлявый»).
- **Уведомление и виджет.** Утреннее уведомление в заданное время и виджет на рабочий стол (Jetpack Glance).
- Телефоны и планшеты (на планшете — две панели), светлая и тёмная тема, Dynamic Color по желанию.

## Стек

Kotlin, Jetpack Compose, Material 3, MVVM + Clean Architecture, Hilt, Room, DataStore, Retrofit +
kotlinx.serialization, Coil, WorkManager, Glance. minSdk 26, targetSdk 37.

## Структура

| Модуль | Что внутри |
|---|---|
| `domain/` | Чистый Kotlin без Android: модели, усреднение моделей (`weather/ModelBlender`), неуверенность, гололёд, восход/закат, алгоритм подбора (`outfit/OutfitRecommender`), калибровка по отзывам, интерфейсы репозиториев, use case'ы. Здесь же unit-тесты. |
| `data/` | Open-Meteo и MET Norway (`remote/`), Room (`local/db/`), настройки DataStore, фото, геолокация, резервная копия, реализации репозиториев, Hilt-модули. |
| `app/` | Экраны Compose (`ui/today`, `ui/forecast`, `ui/wardrobe`, `ui/itemeditor`, `ui/settings`, `ui/locations`), тема, навигация, WorkManager (`work/`), уведомление, виджет. |

### Как подбирается одежда

1. Окно «вне дома» (по умолчанию 8:00–18:00; если оно уже прошло — завтрашнее).
2. Эффективная температура каждого часа = ощущаемая − личная поправка. Расчётная температура —
   ближе к холодной части окна (`мин + 0.2 × перепад`): слой можно снять, но нельзя добавить.
3. По ней — нужная теплота корпуса (сумма слоёв), низа и обуви (`WarmthModel`).
4. Перебор сочетаний «база × средний × внешний слой × низ × обувь» с оценкой: близость к нужной теплоте,
   правила (дождь → непромокаемое, ветер → ветрозащита, снег/гололёд → обувь), возможность снять слой при перепаде
   от 6°, сезон, единый стиль, сочетание цветов, «давно не надевали».
5. Аксессуары по правилам: шапка, перчатки, шарф, зонт, очки и головной убор от солнца.
6. Пояснение, советы («к 13:00 потеплеет — куртку можно снять») и предупреждения о нехватке вещей.

## Сборка через GitHub Actions

Сборка идёт в облаке при каждом `push` (локально нужен только Git).

- Любая ветка: тесты и APK-артефакт `what-to-wear-apk` в разделе **Artifacts** запуска.
- Ветка `main`: то же, плюс релиз `build-N` с файлом `what-to-wear.apk`. Приложение при запуске
  (и по кнопке «Версия» в настройках) находит новый релиз, скачивает его и предлагает установить поверх —
  гардероб и настройки сохраняются.
- `versionCode` = номер запуска CI. У локальных сборок код 1, автообновление для них выключено.
- Релиз публикуется, только если в Secrets репозитория есть ключ подписи: `KEYSTORE_BASE64`,
  `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
- Репозиторий для обновлений задан в `app/build.gradle.kts` (`updateRepo`). У выпущенного приложения его,
  `applicationId` и ключ подписи не менять — иначе обновление не встанет.

## Локальная сборка

Нужны Android Studio (или JDK 17 + Android SDK с platform 37).

```
./gradlew :domain:test :data:testDebugUnitTest   # unit-тесты
./gradlew assembleDebug                          # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease                        # app/build/outputs/apk/release/app-release.apk (подписан debug-ключом)
```
